# LUMERA Beauty Intelligence

# LUMERA — PREMIUM BEAUTY AI E-COMMERCE EXPERIENCE

Build a complete, premium, production-quality web application called **LUMERA**.

Do NOT make this look like a generic AI SaaS template, a hackathon dashboard, or a ChatGPT clone.

LUMERA should look and feel like a **real premium Korean beauty / luxury beauty technology startup** that could launch publicly.

## Brand Name

**LUMERA**

## Brand idea

LUMERA combines visual AI, beauty intelligence and e-commerce decision-making.

The user should be able to:

**Understand their skin → understand their products → decide what to buy → build a routine → visualize a complete look.**

LUMERA should feel intelligent, elegant, trustworthy and premium.

# 3. DESIGN DIRECTION

Create a premium **Korean beauty editorial aesthetic**.

Think:

- modern Korean beauty brands
- luxury skincare
- Apple-level product presentation
- editorial fashion websites
- premium cosmetic stores
- minimal Japanese/Korean-inspired layouts
- sophisticated AI technology

Do NOT copy any existing brand.

Create an original identity.

### Visual characteristics

- warm ivory / soft cream background
- white surfaces
- deep charcoal typography
- muted rose / plum accent
- subtle champagne/beige highlights
- thin elegant borders
- generous whitespace
- large editorial typography
- beautiful product photography
- soft shadows
- rounded but sophisticated cards
- subtle gradients only when tasteful
- premium image compositions

Avoid:

- neon gradients
- excessive purple AI aesthetics
- excessive glassmorphism
- generic blue SaaS dashboards
- cartoon illustrations
- robot/AI icons everywhere
- huge unnecessary borders
- clutter

# 5. ANIMATION SYSTEM

Animation is VERY important.

The website should feel alive, but never gimmicky.

Use **Framer Motion** or equivalent.

Add:

### Page transitions

Soft fade + slight upward movement.

### Hero

Slow image movement / subtle parallax.

### Scroll reveal

Sections fade and slide into view as the user scrolls.

### Product cards

Very subtle hover:

- image zoom 1–3%
- card elevation
- metadata transition

### Buttons

Subtle scale / spring interaction.

### Skin analysis

When analysis runs:

- elegant progress animation
- scanning line over selfie
- subtle radial progress
- changing analysis stages

Example:

Analyzing your image...
↓
Understanding skin profile...
↓
Building your Skin Passport...

### Match score

Animate from:

0 → 87

using a smooth circular progress animation.

### BUY / THINK / SKIP

Animate the verdict into view.

### Routine

Steps should appear sequentially.

### Complete Look

Use a smooth image reveal / transition.

### Important

Animations must be:

- fast
- elegant
- subtle
- performance-friendly

Do NOT make every element bounce.
